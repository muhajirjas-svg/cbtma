❓ Pertanyaan yang Sering Diajukan (FAQ)
Bagaimana cara mengikuti ujian online? ▲
Masuk ke portal dengan username dan password yang diberikan oleh admin/wali kelas. Pilih menu "Soal Ujian", lalu klik tombol "Mulai Ujian" pada paket ujian yang tersedia. Pastikan koneksi internet stabil sebelum memulai ujian.
Apa yang harus dilakukan jika lupa password? ▼
Hubungi admin madrasah atau wali kelas untuk reset password. Jangan berbagi password dengan siapapun. Password dapat diubah melalui menu Pengaturan Akun.
Berapa batas waktu mengerjakan soal ujian? ▼
Waktu ujian ditentukan oleh guru pembuat soal, umumnya antara 60-120 menit. Timer akan ditampilkan di pojok kanan atas halaman ujian. Saat waktu habis, jawaban akan otomatis dikumpulkan.
Bagaimana cara admin menambah data siswa? ▼
Admin dapat menambah data siswa melalui menu "Data Murid" → klik "Tambah Murid" → isi formulir dengan lengkap → simpan. Data dapat juga diimport secara massal menggunakan file Excel.
Bagaimana cara membuat soal ujian baru? ▼
Guru dapat membuat soal melalui menu "Soal Ujian" → klik "Buat Paket Soal" → isi informasi paket ujian → tambahkan soal satu per satu beserta pilihan jawaban dan kunci jawaban → simpan dan aktifkan paket soal.
Bagaimana melihat hasil dan nilai ujian? ▼
Hasil ujian dapat dilihat di menu "Hasil Ujian". Admin dan guru dapat melihat rekap nilai seluruh siswa. Siswa hanya dapat melihat nilai diri sendiri. Laporan dapat diunduh dalam format PDF atau Excel.
